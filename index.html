Vos héros

Colle ici le code de sauvegarde affiché sur ton autre appareil (fiche du héros → « Code de sauvegarde »).

Chaque héros est sauvegardé sur cet appareil, et aussi en ligne quand le monde est joignable : vous jouez quand vous voulez, seul ou en groupe sur le même écran, et vous retrouvez les autres joueurs à la taverne — chat, classement et boss du monde en commun.

Crée ton héros

Le code de récupération n'est pas obligatoire — mais c'est le moyen le plus simple de retrouver votre héros si vous changez d'appareil : il suffira de le taper dans « Reprendre un héros ». Sans lui, seul le code de sauvegarde (visible sur la fiche du héros) fera foi.
